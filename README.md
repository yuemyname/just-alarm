# just alarm — 간단한 아이폰 알람

기본 시계 앱처럼 단순하게 시간, 이름, 반복 요일을 설정하는 SwiftUI 알람 앱입니다. iOS 26 이상에서 AlarmKit으로 알람을 예약합니다.

## 사용법

- 오른쪽 위 + 버튼으로 알람을 추가합니다.
- 시간, 이름, 반복 요일을 정하고 저장합니다.
- 목록의 스위치로 알람을 바로 켜거나 끕니다.
- 알람을 눌러 편집하거나 삭제합니다. 삭제할 때는 확인창이 표시됩니다.

기본 시계 앱과 별도로 알람을 관리합니다. 보호 옵션과 전용 Siri 명령은 제거했습니다. 검색 결과에 한정한 일괄 작업을 제공합니다. 이전 버전의 저장 기록도 시간·이름·요일·켜짐 상태를 유지한 채 읽을 수 있습니다.

## 언어 설정

왼쪽 위 톱니바퀴 → 앱 언어에서 **한국어 / English**를 선택합니다. 선택은 즉시 적용되고 앱을 다시 실행해도 유지됩니다. 처음에는 기기의 선호 언어 목록에서 지원하는 언어를 선택하며, 둘 다 없으면 영어로 시작합니다.

목록·편집·요일·버튼·앱 자체 오류 안내를 번역했습니다. 직접 입력한 알람 이름은 번역하거나 덮어쓰지 않습니다. 시스템 권한 창과 홈 화면 앱 이름은 iOS의 앱/기기 언어 설정을 따릅니다. 이미 예약된 알람의 표시 내용은 예약 시점의 언어를 유지할 수 있으며, 편집 후 저장하면 현재 언어로 예약됩니다.

## 아이폰에서 실행

1. `Jikim.xcodeproj`를 Xcode에서 엽니다.
2. Jikim 대상의 Signing & Capabilities에서 본인의 개발 팀과 고유 Bundle Identifier를 확인합니다. 기존 설정을 유지했습니다.
3. iOS 26 이상 아이폰을 Mac에 연결하고 실행 대상으로 선택합니다. 필요하면 아이폰의 개발자 모드를 켭니다.
4. 실행 후 첫 알람을 추가하면서 알람 권한을 허용합니다.

앱 아이콘, App Store 등록, 다시 알림(스누즈), 사용자 지정 소리는 아직 포함하지 않은 개발용 초안입니다.

## 검증과 범위

이전 버전의 저장 기록을 정상적으로 읽고 다시 저장하는 호환성 테스트를 통과했습니다. 수정한 앱의 시뮬레이터 빌드가 성공했고 실행 화면도 확인했습니다.

Siri의 기본 ‘Turn off all alarms’ 명령을 이 앱이 가로채거나 변경하지 않습니다. 사용자가 관찰한 기본 시계 앱과의 분리 동작을 전제로 사용하되, just alarm 알람의 실제 울림과 Siri 명령 이후 예약 유지 여부는 본인 아이폰에서 확인해야 합니다. 실제 기기에서 음성 명령과 울림을 자동 검증하지 않았습니다.

데이터는 앱 내부에 저장하며 서버나 분석 도구를 사용하지 않습니다.

Apple 문서: https://developer.apple.com/documentation/alarmkit

## 언어 기능 검증

- 아이폰 및 시뮬레이터 대상 빌드 확인
- 한국어·영어 목록 화면 실행 및 배치 확인 (`preview.png`, `preview-en.png`)
- 번역 리소스, 반복 요일, 언어 선택 저장 및 복원, 기본 언어 결정 테스트
- 직접 입력한 이름과 기존 알람 데이터 보존 테스트

`AGENTS.md`에도 앞으로 앱 개발 시 언어 설정을 포함한다는 선호를 기록했습니다. 최신 소스는 `yuemyname/just-alarm` 저장소에서 관리합니다.

## 알람 편집 오류 수정

기존 예약이 있는데 같은 ID로 곧바로 다시 예약하던 흐름을 바꿨습니다. 권한을 먼저 확인하고 기존 예약을 취소한 뒤 변경 내용을 예약합니다. 예약 또는 파일 저장에 실패하면 이전 예약을 복구하며, 복구도 실패하면 재확인이 필요하다는 안내를 표시합니다. 저장 성공 전에는 목록 데이터를 교체하지 않습니다.

아이폰 대상 빌드와 가짜 예약 서비스를 이용한 회귀 테스트를 통과했습니다. 테스트는 연속 편집, 중복 예약 방지, 취소·예약·파일 저장 실패, 이전 예약 복구와 복구 실패, 꺼진 알람 편집, 다시 켜기 및 신규 저장 실패를 포함합니다. 실제 아이폰의 AlarmKit 오류 0을 직접 재현한 것은 아니므로 설치 후 편집·울림을 다시 확인해야 합니다.

기존 앱을 삭제하지 말고, 같은 Bundle Identifier로 Xcode에서 다시 실행하여 업데이트하세요. 보호 옵션이 남아 있는 화면은 이전 버전입니다. 이번 수정본에는 보호 기능 제거와 한국어·영어 설정도 포함되어 있습니다.

## 스와이프, 검색, 일괄 작업

- 오른쪽에서 왼쪽으로 스와이프: 삭제 (삭제 확인 후 적용)
- 왼쪽에서 오른쪽으로 스와이프: 현재 상태에 따라 켜기 또는 끄기
- 검색창: 이름 또는 시간으로 검색. `07:30`, `7:30`, `0730`, `730`, `출근 7:30`을 지원합니다. 영문 이름은 대소문자를 구분하지 않습니다.
- 검색 결과가 있으면 하단에 일괄 작업 메뉴가 표시됩니다. 검색된 알람 전체를 켜기·끄기·삭제할 수 있습니다.
- 작업을 시작한 시점의 검색 결과 ID만 처리하므로 검색 밖의 알람에는 적용하지 않습니다. 삭제 전 개수를 확인합니다.
- 이미 켜진 알람은 일괄 켜기로 다시 예약하지 않습니다. 일부 실패하면 나머지를 계속 처리하고 완료/실패 개수와 실패 항목을 안내합니다.
- 개별 삭제·끄기 및 일괄 작업에도 예약/저장 실패 시 기존 예약 복구 처리를 적용했습니다.

시간 표기·이름·복합 검색, 빈 결과, 검색 결과 범위 제한, 중복 ID 제거 및 부분 실패 테스트를 통과했습니다. 아이폰용 빌드도 확인했습니다. 실제 기기에서 스와이프와 AlarmKit 일괄 예약은 추가 확인이 필요합니다.
